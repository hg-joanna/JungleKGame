# Jungle King Game

## Overview
Jungle King Game is a two-player turn-based strategy game inspired by the classic board game *Jungle* (Dou Shou Qi). Developed in Java using Java Swing, the game challenges players to strategically maneuver animal pieces with unique abilities to either capture the opponent's pieces or reach their home base. Players must consider terrain, special movement rules, and piece rankings, making each match a balance of tactical planning and decision-making.

## Features
- Turn-based two-player gameplay
- Eight unique animal pieces with individual rankings and abilities
- Special movement mechanics, including lion and tiger jumps across lakes and rat swimming
- Trap and home base mechanics that influence strategy
- Interactive graphical user interface built with Java Swing
- Custom pixel-art assets and game board

## Technologies
- Java
- Java Swing
- Object-Oriented Programming (OOP)
